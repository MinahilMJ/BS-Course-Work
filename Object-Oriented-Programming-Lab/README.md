# Object-Oriented Programming (OOP)

This repository contains my Object-Oriented Programming (OOP) course and lab work completed during my university studies. It includes lab assignments, and course assignments focused on learning the core concepts of object-oriented programming using C++.

## Topics Covered
- Classes and Objects
- Constructors and Destructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Operator Overloading
- File Handling
- Exception Handling
- Templates
- Basic Data Structures

## Purpose
This repository serves as an archive of my university coursework, and lab assignments for Object-Oriented Programming.

> **Note:** These programs were written during my university coursework several years ago and may not reflect my current coding style or best practices.
